### 🚀 &nbsp;Featured Projects

#### 🌐 [InterestIntersection](https://github.com/Josue-Tejeda/InterestIntersection)
A high-performance social media platform built using **Django 5**, featuring user connection systems, chronological action streams, custom image bookmarker widgets, and **Redis** for stateful session caching and optimization. Supports social authentication (OAuth) and dynamic image thumbnails.

#### 📊 [ML-learning](https://github.com/Josue-Tejeda/ML-learning)
A collection of custom machine learning notebooks implementing core supervised learning algorithms including **Decision Trees** for medical drug classifications, **K-Nearest Neighbors** for client segmentation, and **Multiple/Simple Linear Regression** models for vehicle fuel/emissions analysis. Built using Scikit-Learn, Pandas, and NumPy.

#### 📝 [blog-app](https://github.com/Josue-Tejeda/blog-app)
A fully containerized Django 5 blogging system backed by PostgreSQL, featuring tag-based categorization, interactive feedback, customized sitemaps, and optimized search engine indexing. Configured with Docker Compose for production-parity development environments.

#### 📦 [Flask Mobile Inventory Manager](https://github.com/Josue-Tejeda/Proyecto-Manejo-de-inventario)
A Flask-based management dashboard for mobile phone inventory, utilizing **SQLAlchemy ORM**, secure session-based authentication (`Flask-Login`), and CSRF protected form handlers (`WTForms`). Deployed ready with **Gunicorn** configurations.
